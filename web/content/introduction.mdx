A public, open initiative to build Riemannian geometry into a living,
machine-verified textbook — a shared foundation anyone can learn from,
contribute to, reuse, and build on.

## What this is

We are turning a course in Riemannian geometry into a single, content-addressed
knowledge graph. Every definition, lemma, and theorem becomes an immutable card;
every formal proof becomes another; and the two are linked. The result is meant
to be read like a textbook, queried like a database, and verified like a program
— all at once.

Manning P. do Carmo's *Riemannian Geometry* serves as the **blueprint** — the
order and scope of the material — not a ceiling. The graph is open: anyone can
add a statement, a proof, a better exposition, or a missing link.

## How it works

The project has two halves of the same mathematics, stored in one graph:

- a **natural-language layer** — the statements, transcribed faithfully;
- a **formal layer** — the same results, written and checked in Lean.

They are joined by cross-source links, so a Lean proof and the prose it
formalizes sit side by side. The formal layer acts as a logical oracle that
exposes gaps in the prose; the prose's structure, in turn, shows where the
formalization is still thin. We close that loop, again and again.
