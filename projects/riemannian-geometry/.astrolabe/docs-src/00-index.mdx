# Riemannian Geometry

A content-addressable knowledge graph of Riemannian geometry: every definition,
theorem and proof is a node, shared between the **natural-language** exposition
(`source: tex`) and the **formal verification** in Lean (`source: lean`), linked
by cross-source edges.

Chapters follow do Carmo, *Riemannian Geometry*.

- **1.** Riemannian metrics
- **2.** Connections; the Levi-Civita connection
- **3.** Geodesics; the exponential map
- **4.** Curvature
- **7.** Complete manifolds — the Hopf–Rinow theorem  ✦ *(written)*

Each chapter composes the shared nodes via `\entryblock{hash}` / `\entryref{hash}{…}`.
