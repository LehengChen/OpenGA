\notready
  A differentiable manifold $M$ has a differentiable partition of unity if and only
  if every connected component of $M$ is Hausdorff and has a countable basis.
  (The ``if'' direction is machine-checked in \cref{lem:dc-ch0-5-6-exists}; the
  ``only if'' direction — a partition of unity forces each component to be
  second countable — has no Mathlib wire path on the current pin and is left to the
  Brickell--Clark citation below.)
