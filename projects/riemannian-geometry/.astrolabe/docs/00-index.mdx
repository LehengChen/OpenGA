# Riemannian Geometry Challenge

A public, open effort to build Riemannian geometry into a living, machine-verified
textbook — a shared foundation anyone can learn from, contribute to, reuse, and
build on.

Every definition, theorem, and proof is a node in one knowledge graph, shared
between a **natural-language** exposition (`source: tex`) and its **formal
verification** in Lean (`source: lean`), linked by cross-source edges. You can read
it like a book, follow the formalization line by line, and see exactly what is
proven and what is still open.

do Carmo's *Riemannian Geometry* is the blueprint — the order and scope of the
material, not a ceiling.
